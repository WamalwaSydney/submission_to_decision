# Evaluation data policy

This directory intentionally contains **templates only**. The project must not claim real precision/recall, ingestion accuracy, task completion, or SUS results until approved de-identified records are placed here.

- `link_labels.csv`: manually labelled receipt-to-report links.
- `ingestion_gold.csv`: manually transcribed report fields for extraction accuracy.
- `usability_sessions.csv`: one row per participant/task, without names or direct identifiers.

Use the synthetic PDF fixtures only for automated regression tests. They are not evidence of Kenyan legislative performance.
